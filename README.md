# Windows Help Desk Troubleshooting Toolkit

## Project Overview

This project is a practical Windows troubleshooting and system administration toolkit developed in a Windows 10 Pro ARM64 virtual machine running in UTM.

The project is designed to demonstrate foundational IT support skills through hands-on exercises, PowerShell commands, troubleshooting procedures, and technical documentation.

## Objectives

- Practice Windows troubleshooting techniques.
- Gather system information using PowerShell.
- Diagnose network connectivity issues.
- Analyze disk space and system resources.
- Investigate Windows services.
- Develop basic PowerShell automation scripts.
- Document technical procedures and troubleshooting results.
- Build a professional IT portfolio using GitHub.
